# Daily Banana

A shared daily Bananagrams-style word grid. Build one connected crossword from every tile, then submit for rarity points.

## Run locally

```sh
npm start
```

Open <http://localhost:4173>.

## GitHub Pages

The Pages workflow generates a deterministic shared rack every day at 00:05 UTC and deploys the static `dist/` folder. No server or ngrok is needed for players.
